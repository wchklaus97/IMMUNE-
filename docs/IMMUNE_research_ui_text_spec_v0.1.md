# IMMUNE 研究系統與 UI／UX 文字規格 v0.1

## 1. 目的

研究系統負責把玩家在關卡中取得的生物質、一度原質、融合核心和抗原樣本，轉化為長期能力、角色資格、地圖擴張和陣容相性。

研究不是單純增加數值，而是逐步改變玩家可以怎樣玩。

## 2. 四個主要介面

### 2.1 科技樹總覽

用途：查看所有研究分支、前置條件、已解鎖項目和下一步方向。

六條主要分支：

1. 防守科技
2. 遠征科技
3. 融合科技
4. 狀態科技
5. 吞噬科技
6. 全面戰爭科技

每個研究節點需要顯示：

- 研究名稱
- 研究分類
- 前置研究
- 消耗資源
- 解鎖效果
- 影響角色或地圖
- 是否已完成
- 是否正在研究

### 2.2 研究室／人體內部漫游

用途：讓玩家在人體內部的研究區域中查看樣本、器官、感染殘留和免疫細胞。

玩家可以：

- 點擊已解鎖的研究區
- 查看病毒、細菌和寄生體樣本
- 觀察角色研究進度
- 發現隱藏研究節點
- 取得研究提示或背景資料

研究室不是獨立戰鬥模式，主要用來承載探索、收藏和世界觀資訊。

### 2.3 關卡前研究準備

用途：在進入關卡前，選擇本次可以使用的研究效果和陣容方向。

主要欄位：

- 關卡名稱與威脅類型
- 預計敵人家族
- 可用研究加成
- 固定型／移動型資格
- 出戰角色
- 預計相性連結
- 預計消耗資源
- 推薦研究路線

玩家可以在這裡調整準備，但不能臨時解鎖尚未完成的研究。

### 2.4 研究—遠征—關卡整合流程

用途：顯示研究如何影響實際地圖和遊戲循環。

流程：

```text
關卡取得材料
→ 研究科技
→ 解鎖角色／移動資格／地圖能力
→ 遠征解除戰爭迷霧
→ 擴大防守空間
→ 面對特殊全面戰爭
→ 取得更高階研究材料
```

## 3. 研究分支內容

### 3.1 防守科技

方向：核心保護、塔位、路線控制和固定炮台。

例子：

- 核心修復效率
- 固定塔生命上限
- 建造區域容量
- 塔間支援距離
- 敵人路線干擾
- 防守波次準備時間

### 3.2 遠征科技

方向：戰爭迷霧、探索距離、遠征補給和疆域擴張。

例子：

- 擴大偵察範圍
- 降低遠征能量消耗
- 提高迷霧事件預覽
- 解鎖相鄰遠征節點
- 增加新區域建造容量
- 遠征撤退時降低傷亡

### 3.3 融合科技

方向：雙家族、三家族、五星 Apex 和融合傳承。

例子：

- 解鎖 T＋B 配方
- 解鎖固定融合形態
- 解鎖三家族融合資格
- 保留雙方一項傳承特質
- 提高融合研究效率
- 解鎖 Apex 研究分支

### 3.4 狀態科技

方向：狀態疊加、狀態持續時間和連鎖反應。

例子：

- 標記持續時間
- 抗體弱點倍率
- 腐蝕破防效率
- 緩速效果上限
- 感染擴散範圍
- 鏈鎖跳躍次數
- 暴擊觸發條件

### 3.5 吞噬科技

方向：巨噬細胞吞噬、原始細胞掉落和回收經濟。

例子：

- 解鎖普通敵人吞噬
- 提高吞噬成功率
- 提高原始細胞掉落率
- 吞噬精英敵人
- 吞噬後回復生命
- 吞噬後獲得額外抗原樣本

### 3.6 全面戰爭科技

方向：移動資格、軍團規模、固定炮台支援和傷亡控制。

例子：

- 解鎖指定角色移動資格
- 增加橫向軍團容量
- 固定炮台支援移動部隊
- 增加撤退時間
- 降低重傷概率
- 解鎖全面戰爭戰術命令

## 4. 研究節點狀態

每個研究節點使用四種狀態：

- 未發現：被戰爭迷霧或前置條件遮蓋
- 已發現：玩家看見名稱和效果，但尚未具備條件
- 可研究：資源和前置條件已滿足
- 已完成：效果永久生效

## 5. 研究與角色的關係

研究可以解鎖：

- 角色卡使用資格
- 固定／移動資格
- 被動天賦
- 主動技能資格
- 陣容相性
- 融合配方
- Apex 形態

不是每個角色都需要主動技能。部分角色只透過被動和陣容連結產生價值。

## 6. UI 導航建議

主流程：

```text
核心基地
→ 研究總覽
→ 研究室漫游
→ 選擇研究
→ 關卡前準備
→ 進入自由防守／遠征／全面戰爭
```

任何介面都應該讓玩家看見：

- 目前擁有資源
- 下一個可解鎖目標
- 研究會改變什麼玩法
- 研究完成需要什麼條件
- 可以配合哪些角色或陣容

## 7. 第一版製作範圍

第一個可玩原型只需要：

- 防守科技 3 個節點
- 遠征科技 3 個節點
- 融合科技 2 個節點
- 狀態科技 2 個節點
- 吞噬科技 2 個節點
- 全面戰爭科技 2 個節點

總共 14 個研究節點，足以測試研究是否真正改變 15–20 分鐘的核心循環。

不應在原型階段製作完整 57 種陣容研究或全部 Apex 分支。

## 8. 待確認事項

- 研究是否即時完成，或需要短時間等待。
- 研究材料是否可以撤回或重置。
- 同一關卡可否帶入多個研究加成。
- 研究室漫游是否需要可操作角色。
- 研究節點是否受地圖區域解鎖限制。
- 研究是否會永久保留在新局，或按模式重置。

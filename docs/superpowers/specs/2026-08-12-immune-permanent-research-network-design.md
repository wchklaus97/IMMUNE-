# IMMUNE 永久研究網絡設計規格 v1.0

## 1. 設計目標

`IMMUNE` 的研究介面是一張以角色家族為空間骨架、以永久知識與可裝備研究協議為成長內容的放射式免疫網絡。它必須容納 200 個真實節點、31 個角色身份、15 組雙家族相性、6 組三家族融合、狀態化學與 Apex 終局路線。

研究地圖的目標不是累積大量細小數值，而是逐步解鎖新的角色資格、戰鬥行為、固定／移動能力、陣容關係、融合角色和遊戲規則。

## 2. 核心區分

### 2.1 永久知識

完成後永遠生效，不佔關卡前配置容量：

- 角色使用資格
- 固定炮台／移動資格
- 融合配方
- 地圖探索功能
- 基礎吞噬資格
- 基礎狀態規則
- 核心防守與遠征規則

### 2.2 研究協議

研究後永久解鎖，但進入關卡前只能裝備有限數量：

- 強力陣容相性
- 融合傳承特質
- 狀態連鎖反應
- 高階撤退／救援協議
- 特殊全面戰爭戰術
- Apex 加成

初期協議帶寬為 6，後期最多提升至 10：

- 普通協議消耗 1 帶寬
- 核心協議消耗 2 帶寬
- Apex 協議消耗 3 帶寬
- 同一關卡最多啟動一個 Apex 協議
- 關卡外可以免費更換協議

## 5. 基礎角色研究骨架

每個基礎角色有 8 個專屬研究，但效果按照生物學功能與定位不同：

1. 角色使用資格
2. 生物學核心被動
3. 固定炮台專精
4. 移動資格或固定支援資格
5. 目標選擇／戰鬥行為
6. 陣容連結增幅
7. 天賦覺醒或特殊被動
8. 家族終極研究

角色不必擁有主動技能。沒有主動技能的角色以特殊被動、AI 行為、資源轉換或支援協議代替。

## 6. 雙家族相性路線

每組雙家族使用四階段內容，其中角色身份錨點與三個研究節點合計四個節點：

```text
★1 基礎相性研究
→ ★2 強化協同／共鳴研究
→ ★3 命名實體融合角色錨點
→ ★4 傳承特質研究協議
→ 共用外環 ★5 三融合／Apex 資格
```

★5 使用共用的三融合或 Apex 資格節點，不為十五組各自重複製作。

## 7. 三融合與 Apex 條件

- 三融合資格需要三個來源基礎角色身份。
- 三組兩兩相性中，任意兩組達到 ★2 即可；不要求先製作三個實體雙融合。
- 三融合角色錨點後有戰場定位、專屬規則與 Apex 連結三項研究。
- 隱藏 Apex 需要對應雙家族 ★4、Boss／遠征發現條件與指定材料。
- `IMMUNE PRIME` 需要六個家族終極研究及任意三個命名三融合成果，不要求完成其餘 199 個節點。

## 8. 依賴圖規則

研究網絡是一張無循環依賴圖：

- 普通節點最多一個必要前置。
- 角色、融合和 Apex 節點最多兩個必要前置。
- 全部必要條件與任選其一條件使用不同符號。
- 實線：必須完成的前置研究。
- 雙色粗線：兩個家族共同解鎖融合。
- 虛線：可選或替代路線。
- 點線：陣容相性資訊，不是前置條件。
- 角色死亡只失去可部署個體，不會刪除角色身份、配方或永久研究成果。

## 9. 放射式地圖資訊架構

```text
中央：免疫核心
內環：六大通用科技與七種狀態化學
家族環：六個基礎角色及角色專屬研究
組合環：十五組雙家族相性與融合角色
進化環：六個三家族角色及研究
最外環：三個隱藏 Apex 與 IMMUNE PRIME
```

六個 60° 扇區按照角色家族劃分。六大科技分類不佔用空間方向，而使用節點形狀、圖示和篩選標籤表達：

- 空間位置＝角色家族
- 節點形狀／圖示＝研究分類
- 節點外圈與符號＝解鎖狀態
- 連線樣式＝依賴、融合、替代或相性

## 10. 大型地圖交互

### 10.1 縮放與平移

- 縮放範圍：0.35×–2.4×。
- 滾輪／雙指以游標位置為中心縮放。
- 拖曳空白區域平移。
- 雙擊角色錨點自動聚焦角色研究群。
- 提供「顯示全圖」、「返回核心」、「聚焦目前路線」。
- 右下角顯示迷你地圖與目前視窗範圍。
- 保存玩家上次查看的位置與縮放比例。

### 10.2 資訊密度

- 0.35–0.55×：只顯示六個家族扇區、31 個角色錨點及總進度。
- 0.56–1.0×：顯示普通研究節點、主要連線與角色名稱。
- 1.01–1.6×：顯示節點名稱、研究類型與狀態。
- 1.61×以上：顯示成本、簡短效果與前置提示。

小節點的視覺直徑可以是 18–24px，但可點擊範圍至少為 44px。

### 10.3 聚焦與連線

- 預設只顯示低亮度主幹，避免形成蜘蛛網。
- 選擇角色時，亮起其祖先、專屬研究、五個雙家族方向與可達後續。
- 選擇融合時，只亮起兩個來源家族和後續進化。
- 無關內容降至 10%–20% 亮度，但不改變位置。
- 篩選只淡化節點，不刪除或重新排列節點。

## 11. 搜尋與篩選

搜尋支援：

- 研究名稱
- 角色名稱
- 狀態名稱
- 敵人類型
- 效果關鍵字，例如移動、吞噬、腐蝕、修復
- 影響模式：防守、遠征、全面戰爭

篩選支援：

- 六個角色家族
- 六種科技分類
- 已完成、可研究、缺資源、缺前置、未發現
- 只看目前陣容相關
- 只看可負擔
- 角色、普通被動、能力資格、融合、Apex

未發現內容不會因搜尋而提前顯示名稱或效果。

## 12. 節點狀態

- 未發現
- 已揭示但鎖定
- 前置完成但資源不足
- 可研究
- 已選擇
- 已追蹤
- 已完成
- 角色卡／材料條件不足

狀態不能只使用顏色：

- 鎖頭：前置不足
- 空心外圈：資源不足
- 脈衝光圈：可研究
- 實心細胞膜：已完成
- 圖釘：已追蹤
- 白色焦點圈：目前選擇

## 13. 節點詳情面板

右側面板顯示：

- 研究名稱與類型
- 所屬／關聯角色
- 實際玩法效果
- 影響的模式
- 可點擊跳轉的前置條件
- 消耗與目前擁有量
- 未解鎖原因
- 完成後開放的下一批節點
- 追蹤研究
- 開始研究

不使用泛用 `Level 1／5`。改用研究環層、研究類型、物種階段及解鎖狀態。

若資源不足，直接顯示缺口與取得方式，例如：

```text
仍缺：一度原質 ×3
取得方式：遠征感染節點／巨噬細胞回收
```

## 14. 解鎖回饋

普通研究：

1. 能量沿前置連線流入新節點。
2. 節點由閉合細胞膜轉為發光成熟狀態。
3. 資源數值平滑扣除。
4. 新可研究節點依序亮起。
5. 詳情面板顯示本次永久改變的玩法。

角色、融合和 Apex 解鎖額外顯示：

- 角色 3D 頭像／旋轉縮圖
- 雙家族顏色匯流
- 新研究區域揭示
- 可加入陣容與後續進化提示

## 15. 資源分工

| 資源 | 研究用途 |
|---|---|
| 免疫能量 | 只在關卡內使用，不進永久研究 |
| 生物質 | 關卡強化與正常修復；只允許有限結算轉化 |
| 抗原樣本 | 普通科技、角色天賦與狀態研究主要貨幣 |
| 一度原質 | 角色錨點、覺醒與重要規則節點 |
| 融合核心 | ★3 實體融合、三融合與 Apex |

原始細胞與完整角色卡是角色專屬前置材料，不是第六種通用貨幣。受傷修復主要消耗時間與生物質；一度原質只用於可選擇的即時修復。

## 16. 解鎖節奏

- Demo：可接觸 18–24 節點，每個 15–20 分鐘循環解鎖 2–4 個普通節點，或儲存資源準備重要節點。
- 主線 4–6 小時：完成約 45–60 個節點。
- 完整內容 15–25 小時：發現全部主要路線，完成約 130–160 個節點。
- 200／200：非必要的精通與收藏目標。
- 玩家最多同時追蹤三個研究目標；系統顯示所需前置與總資源，但不自動購買。

## 17. 驗收標準

- 全圖縮放狀態下仍可辨認 31 個角色錨點。
- 1280×720 與 Steam Deck 1280×800 不出現面板遮擋。
- 玩家可在 10 秒內找到「T 細胞移動資格」。
- 點擊鎖定節點後，一次操作內知道缺少的條件及取得方法。
- 選擇雙家族融合時，兩條來源角色路線清楚亮起。
- 篩選後節點位置不變。
- 200 個節點平移、縮放及聚焦保持流暢。
- 未發現內容不因搜尋而劇透。
- 所有文字由 HTML／遊戲 UI 程式渲染，不烘焙進背景圖片。

## 18. 第一個可玩 UI 垂直切片

第一版互動 Demo 實作完整 200 節點資料結構，但初始只揭示 18–24 個節點。可玩旅程為：

```text
打開全圖
→ 聚焦 T 細胞
→ 查看移動資格的前置路線
→ 追蹤研究
→ 完成普通研究
→ 兩個新節點亮起
→ 切換至 T＋B 融合
→ 查看雙來源依賴與缺少材料
→ 配置一項已解鎖研究協議
```

這個垂直切片通過後，才擴展研究室漫游、完整關卡前協議配置與解鎖動畫。

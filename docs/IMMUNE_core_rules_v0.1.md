# IMMUNE 核心規則 v0.1

## 1. 產品核心

`IMMUNE` 是一款以人體內部為舞台的 3D 免疫細胞策略塔防遊戲。玩家由核心周圍的小型防守區開始，穿越戰爭迷霧進行遠征，逐步擴張免疫疆域，並在特殊全面戰爭中承受真實傷亡風險。

核心流程：

```text
自由防守 → 遠征擴張 → 特殊全面戰爭 → 修復／重新部署 → 下一輪
```

## 2. 固定防守

- 初始地圖以核心為中心，整體約 5×5 格。
- 開始時只有核心周圍的小型區域可用。
- 玩家可自由放置固定塔；塔的位置會影響敵人路線與防守範圍。
- 勝利條件：守住核心並完成該關卡的防守要求。
- 失敗條件：核心生命歸零。
- 核心受傷後需要短時間修復，修復期間限制再次承受高強度戰鬥。

## 3. 戰爭迷霧與遠征擴張

- 未探索區域由戰爭迷霧遮蓋。
- 遠征只能從已佔領區向相鄰未知區域推進。
- 遠征成功後，清除感染節點並解鎖新的防守／建造空間。
- 地圖骨架固定，但敵人、事件、部分場景內容可以隨機。
- 地圖擴張會增加塔位、路線、組合空間和資源選擇。
- 遠征不是單純獎勵關，而是改變後續防守地圖的成長系統。

## 4. 特殊全面戰爭

特殊全面戰爭是高風險戰鬥，不是每關固定出現。

### 觸發來源

1. 遠征擴張時發現大型感染據點。
2. 接近 Boss 防守區時，敵方特殊部隊主動突襲。
3. 感染值過高或特殊條件達成，觸發緊急全面戰爭。

### 戰鬥規則

- 免疫細胞可組成橫向軍團推進。
- 部分角色仍然只能作固定炮台，提供後方支援。
- 玩家可以即時撤退。
- 撤退會保留本次傷亡、受傷、感染和資源損失。
- 敵人可以直接攻擊並摧毀我方出戰角色。

### Boss 類型

- 進攻型 Boss
- 防守型 Boss
- 隨機攻守型 Boss

## 5. 角色生命狀態

```text
正常 → 受傷 → 修復
正常／受傷 → 死亡
```

- 受傷角色：暫時不能出戰，等待時間恢復 HP。
- 死亡角色：永久失去，需要重新獲取或合成。
- 核心歸零：本局關卡失敗，需要重新開始。
- 角色死亡與玩家關卡失敗是兩個不同層級的損失。

## 6. 固定形態與移動形態

- 角色初始不一定具備移動能力。
- 研究科技可令指定細胞由固定塔解鎖為可移動單位。
- 在全面戰爭中，未完成移動研究的角色仍只能作固定炮台。
- 固定形態：射程、防守、路線控制、支援。
- 移動形態：橫向推進、目標選擇、前線交戰。
- UI 必須清楚顯示固定／移動資格、受傷、死亡與研究狀態。

## 7. 資源與成長

暫定五種資源：

1. 免疫能量：關卡內部署、遠征和戰術技能。
2. 生物質：短期戰鬥與角色強化。
3. 一度原質：永久材料與研究。
4. 融合核心：雙家族／三家族融合。
5. 抗原樣本：角色研究、召喚與配方解鎖。

角色成長不以傳統等級為核心，而是由以下項目決定：

- 角色卡是否取得
- 研究成果
- 細胞合成
- 陣容相性
- 裝備與被動加成

## 8. 角色與陣容

- 初期可獲得角色數量有限，後續透過關卡、抽取、吞噬與合成增加。
- 每個角色可有被動天賦；只有部分角色需要主動技能。
- 主動技能是否有特效，按生物功能和遊戲重要性決定。
- 陣容相性由家族關係、角色數量和研究結果共同決定。
- 目標不是建立唯一最優解，而是令不同陣容在不同敵人與地圖中各有價值。

## 9. 獲取與吞噬

- 每關完成可獲得一張完整角色卡或指定解鎖獎勵。
- 巨噬細胞等吞噬型角色可在關卡內吞噬敵人。
- 吞噬有概率獲得原始細胞。
- 精英與 Boss 提供更高階材料或保證獎勵。
- 吞噬掉落需要保底或累積進度，避免完全依賴運氣。

## 10. 狀態系統

已確認的核心狀態包括：

- 標記
- 抗體
- 腐蝕
- 緩速
- 感染
- 鏈鎖
- 暴擊

規則：

- 狀態可以疊加，但部分疊加需要研究科技。
- 只有合理的狀態組合才會產生連鎖反應。
- 病毒、細菌、寄生體和突變細胞可以擁有專屬抗性或免疫。

## 11. 教學順序

```text
自由防守 → 遠征擴張 → 特殊全面戰爭
```

- 前期先讓玩家理解核心防守。
- 中期介紹戰爭迷霧和疆域擴張。
- 後期再引入角色永久死亡、全面戰爭和高風險 Boss。

## 12. 待平衡項目

- 5×5 地圖中初始可用格數。
- 九宮格每次擴張增加的格數。
- 每關波數與固定／隨機波比例。
- 角色受傷修復時間。
- 角色死亡後的重新取得難度。
- 五種資源的實際掉落與消耗數值。
- 全面戰爭中固定炮台和移動軍團的比例。
- 「救你一命／留返啖氣」機制的冷卻和使用限制。

## 13. 本輪已確認的核心決策

### 13.1 戰鬥勝負與傷亡

- 固定防守的主要勝利條件是守護核心；核心生命歸零即失敗。
- 遠征與特殊全面戰爭可以中途撤退。
- 撤退後必須保留本次受傷、死亡、感染和資源損失，不會回復成未出戰狀態。
- 角色失去全部生命後視為死亡，死亡角色不能再次上場；受傷角色需要等待修復。
- 角色死亡、核心歸零和整局失敗是不同層級的結果。

### 13.2 地圖與戰爭迷霧

- 初始核心區是小型自由防守地圖，外圍由戰爭迷霧遮蓋。
- 地圖以 5×5 作為主要邊界概念，擴張區域以九宮格節點逐步解鎖。
- 地圖骨架固定，但敵人、場景事件和部分戰鬥內容可以隨機。
- 遠征的主要價值是解除迷霧、擴大可防守空間，以及增加塔位、路線和陣容組合，而不是單純取得一次性獎勵。
- 失敗後原則上重新開始本局／本次地圖進度；保命或救援機制是否保留部分成果，列入平衡測試。

### 13.3 固定與移動資格

- 固定塔和移動單位不是單純外觀切換，而是由研究成果決定的能力資格。
- 尚未完成移動研究的角色，在特殊全面戰爭中只能作固定炮台。
- 已解鎖移動資格的角色才可加入橫向軍團。
- 全面戰爭中仍然允許固定炮台留在後方支援移動軍團。
- 玩家不需要頻繁手動切換每個角色的形態；資格和可用狀態由 UI 清楚顯示。

### 13.4 角色設計原則

- 角色主動技能數量不必一致，並非每個角色都需要主動技能。
- 主動技能應根據該細胞的生物學功能、戰鬥定位和陣容作用決定。
- 後期角色深度主要來自被動、主動加成、研究成果、裝備和陣容相性，而不是大量新特效。
- 角色需要分類為坦克、輸出、支援、偵察、吞噬或固定炮台等定位，以維持家族平衡。

### 13.5 成長與獲取原則

- 關卡可以提供完整角色卡，作為穩定的角色獲取途徑。
- 吞噬型角色在關卡中吞噬敵人，有概率獲得原始細胞。
- 角色成長不以傳統數值等級為核心，而以角色卡、合成、研究、陣容和裝備為主。
- 角色需要先取得相應卡片或材料，才可以進行合成、強化或研究；不使用付費抽卡。
- 五種資源的實際數量、掉落率和成本，要在關卡路線與獲取規則固定後再計算。

### 13.6 狀態與敵人

- 狀態可以疊加，但部分疊加需要研究或科技解鎖。
- 狀態連鎖只在合理的前提和指定組合下發生，不是所有狀態都互相反應。
- 病毒、細菌、寄生體和突變細胞可以有自己的抗性、免疫、主動技能或被動特性。
- 敵人的主要設計方向是針對玩家陣容形成相剋與反制，而不是只提高生命值和傷害。

### 13.7 玩家流程與教學

- 玩家不能在開局自由選擇模式；主線教學順序固定為：自由防守 → 遠征擴張 → 特殊全面戰爭。
- 自由防守是小型核心區，遠征從這張地圖的戰爭迷霧向外展開。
- 特殊全面戰爭是遠征、Boss 防守區或感染失控時觸發的特殊戰爭，不是每一關固定出現。

### 13.8 地圖擴張的代價

- 地圖變大會同時增加可用空間、敵人路線和防守責任。
- 擴張不只是純增益；後期可能需要同時守護多個方向，令玩家不能只集中於一條路線。
- 遠征獎勵、可建造空間和敵方壓力需要共同平衡，避免遠征永遠優於防守。

## 14. 第一個可玩原型驗收目標

第一個可玩原型必須讓玩家在約 15–20 分鐘內完成一次完整循環：

```text
自由防守 → 遠征探索 → 解鎖新區域 → 特殊全面戰爭 → 修復／結算
```

建議時間分配：

- 自由防守：5–7 分鐘
- 遠征與解除戰爭迷霧：3–4 分鐘
- 新區域建立與陣容整理：1–2 分鐘
- 特殊全面戰爭：4–5 分鐘
- 修復、傷亡結算與獎勵：1–2 分鐘

原型只需要包含：

- 一個 5×5 地圖邊界
- 核心周圍初始防守區
- 一個可解除的戰爭迷霧區域
- 一個遠征感染節點
- 一場特殊全面戰爭
- 六個基礎免疫角色的簡化版本
- 病毒與細菌兩類基礎敵人
- 免疫能量、生物質和一度原質三種測試資源

原型驗收標準：

1. 玩家能理解核心生命、戰爭迷霧和遠征目標。
2. 玩家能完成至少一次固定防守和一次橫向全面戰爭。
3. 遠征成功後，地圖確實增加可防守或可建造空間。
4. 角色受傷、撤退和修復狀態能被玩家理解。
5. 15–20 分鐘內可以完成循環，而且不需要依賴完整抽卡或複雜技能樹。

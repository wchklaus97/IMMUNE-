## Changes that affect this repository

- `latest` now resolves to Meshy 7, not Meshy 6.
- Text to 3D and Image to 3D support Meshy 7; Ultra mode adds 5 credits.
- `model_type: lowpoly` is deprecated. New game assets should use
  `model_type: smart-topology` with `ai_model: meshy-t2` when its 15k-face ceiling
  fits the asset.
- Smart Topology generates separated, triangle-only parts and accepts a target of
  100-15,000 faces. It costs 5 credits untextured or 15 credits textured.
- `hd_texture` is deprecated. Use `texture_resolution: 2k|4k|8k` for workflows
  that genuinely need Meshy textures.
- Text to 3D refine and Meshy 7 image workflows can use 2k/4k/8k textures. 8k
  increases the task price.
- Text/Image to Image gained background removal; Multi-Image to 3D gained multiple
  texture-guide images; Text to Motion can now feed the Animation API. None is
  needed for the non-humanoid base M asset.
- Failed tasks report `consumed_credits: 0`, but ambiguous client-side POST timeouts
  still require task-list inspection before retrying.

## Selected M-cell route

`CHAR-BASE-M.png` is already a clean, locked, square reference. The selected route
is therefore Image to 3D rather than Text to 3D:

1. Validate the local source, manifest, exact endpoint, target range, format and
   expected cost without network access.
2. Require explicit `--execute --approve-credits 5` before task creation.
3. Query the free balance endpoint and block if it cannot cover the exact gate.
4. Create one Smart Topology task: `meshy-t2`, triangle, 8,000 target faces,
   untextured, GLB only.
5. Poll using bounded backoff. A terminal failure stops the workflow; there is no
   blind regeneration.
6. Stream the GLB to a partial file, require a plausible size and binary `glTF`
   header, then atomically rename it.
7. Record task ID, API version, actual `consumed_credits`, face count and files in
   `meshy_output/`.
8. Import into Godot, replace materials with the shared wet-gel shader, confirm the
   one-body/two-short-arm silhouette, and run combat plus performance regressions before
   replacing the blockout.

Meshy's own texture generation is intentionally disabled: the required jelly look
depends on live wet specular, subsurface-style transmission and restrained wobble
under the game's lighting. Baking those cues into a base-color texture would make
the result flatter and less controllable.

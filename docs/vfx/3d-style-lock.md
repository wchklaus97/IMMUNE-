## 美術鎖

- 材質：誠實濕果凍（高光、皮下透光、有機凸起）。金屬只當鎖在殼上的配件。
- 相機：黑底、抬高 isometric 3/4。進引擎後綠幕／透明另做，不改概念圖。
- 雙形態：同一顆核。固定 = BaseKit 裙。移動 = 輪／鰭／偽足螺栓在殼上。A = 中繼碟，無腿、無走路骨。
- A 固定與中繼可以都很像（碟可共用）；那是 1 秒職責切換，不是兩隻角色。

## 其餘角色重生契約

舊 2D 立繪不算數。常見失敗：對半上色、兩隻站一起、弓／放大鏡道具、組織台、T 畫成青、融合沒有父母辨識。

| 批次 | 檔 | 做法 |
|---|---|---|
| 0 六基礎 2D | 18（圖鑑＋固定＋移動／中繼） | **已重生 2026-08-14**。綠幕正面圖鑑，身分跟鎖住的 3D 走 |
| 1 雙融合 | 45（15×3） | 同一顆核＋父母配件，不是對半漆 |
| 2 三融合 | 18（6×3） | 三件套配件，仍一顆核一張臉 |
| 3 Apex／Prime | 12（4×3） | 終局配件，不是彩虹皇冠 |

融合配方：父母家族色當配件混在**一顆**濕果凍上。T 炮、B 金 Y、M 爪紅球、N 加特林、A 碟無腿、D 樹枝。含 A 的融合沒有走路骨。

- 移動鋸屑／噴濺
- 凍結換第二具身體、對半兩色當兩隻角色
- 現在就做融合 3D 出模

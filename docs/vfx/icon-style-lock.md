# IMMUNE 圖示風格鎖

3D 戰鬥概念已鎖：`docs/vfx/3d-style-lock.md`（12 張，不再重畫）。

材質基準：`assets/characters/CHAR-BASE-M.png`
（膠質半透明、濕高光、皮下透光、有機凸起——不是硬塑膠玩具。）

研究圖示**不含角色、不含臉**。UI 自己裁圓，圖裡禁止再畫圓框。

**顏色：** 只有同一家族線才鎖家族色。CORE／通用科技／狀態／協議等分類用各自的科技色，不必跟巨噬紫。

## 必做

- 1:1，主體約佔畫面 70%
- 膠質 3D：濕高光、輕微透光、有機表面
- 平底 `#00ff00` 綠幕，物件懸空
- 研究圖：只有符號／器官／武器物件
- 技能圖若出現細胞，材質必須跟巨噬那張一樣

## 禁止

- 圓框、徽章環、霓虹圈、封印、打勾
- 深藍圓底
- 組織台、三腳架、粉紅肉盤
- 臉、眼睛、完整角色（研究圖示）
- 文字、字母、數字


## 禁止

- 圓框、徽章環、雙線霓虹圈、金色封印、打勾章
- 深藍圓底、泡泡散景當「徽章」
- 組織台、三腳架底座、粉紅肉盤
- 移動碎屑／鋸屑粒子
- 任何文字、字母、數字、浮水印
- 換臉、換鏡頭高度、換材質（有的磨砂有的金屬）

## 六家族主色（不可漂）

| 家族 | 鎖 |
|---|---|
| T | 橘球 `#ff8a3d`、C 形刺、中央炮 |
| B | 紫藍 `#8b6cff`、胸前金 Y |
| M | 薰衣草 `#c9a0ff`、雙爪、紅球 |
| N | 橄欖 `#8fb03a`、加特林必須在 |
| A | 金 Y 身體 `#f2b84b`、中繼碟不是腳 |
| D | 橘樹突枝 `#ff9b58` |

融合：對半或配件混色，仍是**同一顆球**，不是兩隻站一起。

## 槽位只改姿勢，不改人

- PASSIVE / P1 / ROLE / GATE：靜、握符或光暈
- ACTIVE / P2 / RULE：打一發，畫面裡不要敵人全身
- FIXED / DEF：肢體收起當炮台，無底座
- APEX / ULT：同一張臉放大光，不是新角色
- PROTO：小封印浮在角色前，不是文件圖示

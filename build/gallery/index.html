标准参考

所有对比的最终标准：黑底、3/4 俯视、湿果冻半透明、额头圆孔、对称眼、钟形轮廓。

验收项要求
额头孔浅凹圆盘 + 小黑洞，不能是凸起的第三只眼
眼睛对称杏仁眼 + 小皱眉，无鼻子凸起
轮廓钟形，四只下垂肢体，下摆有波浪裙边
材质半透明湿果冻，边缘有光晕，表面有细密颗粒感
动画全程额头孔可读

基准模型（Tripo 原始）

起点是你提供的 Tripo remesh：5044 面、3277 顶点、1 套 UV、1 张贴图。 问题：额头火山口、塑料材质、鼻凸、眼不对称、身形偏矮胖。 数据见 t-raw-report.json。

几何修复（头部已通过）

Blender 脚本推顶点修复，输出 CHAR-BASE-T-fix.glb（7522 面）。 修复报告：fix-report.json、 t-fix-report.json。 可在 inspect/ 下载两个 GLB 做 Blender 对比。

湿果冻材质迭代（Godot shader）

自定义 wet_gel.gdshader + gel_look.gd。 五轮主要问题：过曝 → 薄处不发光 → 太暗像塑胶 → 颜色对了但太光滑 → 第 5 轮打开凹点颗粒感。

工具脚本（build 根目录）

这些脚本自动生成上面的截图和数值，不是游戏运行时文件。

脚本用途
bl_shots.pyBlender 无头导入 GLB → 六角度截图 + mesh JSON
bl_fix_t.py / bl_fix_t_ops.py几何修复：推顶点改孔/眼/嘴
gel_compare.py材质像素对比（--zones --detail --ink）
anim_sheet.py / render_anims.ps1动画条合成
an_*.py（约 20 个）几何/材质/轮廓的专项分析
crit*.py / critic*.py各轮独立评审的测量脚本
bl_open_compare.py打开 Blender GUI 左右对比两个 GLB

Godot 侧渲染工具在 godot/immune/tools/shot.gd（本页所有 t-gel-* / t-anim 图都由它生成）。

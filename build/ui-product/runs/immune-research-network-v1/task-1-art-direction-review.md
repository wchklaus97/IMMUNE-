# Task 1 Art Direction Review

## Verdict

All independent reviews recommend the same hybrid direction:

> Use Concept A for information architecture and interaction; use Concept B for organ texture, danger, cellular materials and organic signal lines.

Concept A remains the production UI baseline because 200 nodes, 31 character anchors, four edge languages and eight runtime states require high legibility at 1280×720 and 1280×800.

## Non-negotiable visual identifiers

1. One luminous central immune core.
2. Five concentric progression rings.
3. Six stable 60-degree family sectors.
4. Organic local clusters rather than evenly spaced dots.
5. Exactly 31 anchors visibly larger than normal research nodes.
6. Four anchor silhouettes for base, pair, triple and Apex identities.
7. Pair fusions at family borders and higher fusions on outer rings.
8. Four visibly distinct edge languages.
9. Selected route at full intensity and unrelated content at 10–20%.
10. Search, detail inspector, protocol dock and minimap remain operationally clear.

## Comparison rule

Concept A and Concept B must use the same 1920×1080 composition, reveal state and selected T-cell route. The responsive Steam Deck concept is produced only after one visual direction is approved.

## Rejection conditions

- Generic card-grid dashboard.
- Decorative 30-node or 204-placeholder tree presented as 200 real nodes.
- All node labels visible at overview scale.
- Uniformly bright spiderweb connections.
- Anchors and ordinary nodes at the same size.
- State communicated by color alone.
- Human tissue texture obscuring selected route or text.
- Baked production UI text or controls inside a raster background.

## Scoring weights

- Target and route discoverability: 30%.
- 31 anchors and six-sector recognition: 20%.
- 720p / Steam Deck adaptation: 20%.
- Detail and resource readability: 15%.
- IMMUNE atmosphere: 10%.
- HTML/SVG implementation feasibility: 5%.
